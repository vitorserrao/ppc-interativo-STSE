# ⚡ PPC Interativo - Sistemas de Energia

## 📌 Sobre o Projeto

Este projeto foi desenvolvido na disciplina de **Extensão I** com o objetivo de transformar o **Projeto Pedagógico de Curso (PPC)** de Sistemas de Energia em uma experiência **visual, interativa e orientada ao mercado**.

A proposta surge a partir de um problema real identificado:

> Muitas empresas não conhecem o curso de Sistemas de Energia e, por isso, não compreendem o valor e o potencial dos profissionais formados na área.

---

## 🎯 Objetivo

Criar uma plataforma que:

- Torne o PPC mais **claro e atrativo para alunos**
- Demonstre para empresas as **competências reais do profissional**
- Conecte disciplinas com **aplicações práticas no mercado**
- Destaque **habilidades, tecnologias e problemas reais resolvidos**
- Aumente a **visibilidade e empregabilidade dos alunos**

---

## 🚀 A Ideia

O projeto propõe a criação de um:

### 👉 **PPC Interativo**

Uma plataforma que transforma um documento técnico e estático em:

- 🗺️ Linha do tempo do curso (fases)
- 📚 Disciplinas explicadas de forma simples
- 🛠️ Tecnologias utilizadas
- 🎯 Habilidades desenvolvidas
- 🧠 Competências adquiridas
- 🚨 Problemas reais que o profissional resolve

---

## 🧩 Funcionalidades

### 🎓 Para Alunos
- Visualização clara da jornada do curso
- Entendimento prático das disciplinas
- Conexão entre teoria e mercado
- Direcionamento de carreira

---

### 🏢 Para Empresas
- Compreensão do perfil do profissional
- Visibilidade das habilidades técnicas
- Clareza sobre o valor gerado
- Acesso a talentos em formação

---

### 👨💼 Banco de Talentos (proposta)
- Listagem de alunos com:
  - Tecnologias dominadas
  - Habilidades
  - Áreas de interesse
  - Problemas que conseguem resolver

---

## 🧠 Diferencial do Projeto

O projeto não apenas descreve o curso, mas traduz o conhecimento acadêmico em:

👉 **Valor de mercado**

Foco em responder:

- Que problemas esse profissional resolve?
- Onde ele gera impacto?
- Como ele ajuda empresas na prática?

---

## ⚙️ Estrutura do Curso (Resumo)

O curso é organizado em 6 fases:

- **Fase 1:** Base técnica (matemática, física, lógica)
- **Fase 2:** Fundamentos elétricos e análise
- **Fase 3:** Aplicação prática (medição, programação, instalações)
- **Fase 4:** Sistemas elétricos e eficiência energética
- **Fase 5:** Mercado, gestão e comercialização de energia
- **Fase 6:** Consolidação profissional (TCC e projetos)

---

## 💡 Problema Resolvido

Este projeto atua diretamente em:

- Falta de conhecimento das empresas sobre o curso
- Baixa percepção de valor do tecnólogo
- Dificuldade dos alunos em entender o fluxo do curso
- Distanciamento entre academia e mercado

---

## 🛠️ Tecnologias

O projeto foi implementado com:

- **React** → estrutura da interface (front-end)
- **TypeScript** → tipagem e organização do código
- **Vite** → ferramenta de build ultra-rápida
- **Tailwind CSS** → estilização moderna e responsiva
- **Framer Motion** → animações e interatividade fluida
- **Lucide React** → biblioteca de ícones consistentes
